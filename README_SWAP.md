# Astronaut + casual crew + bunk sleep (Milestone 04)

Copy the folders in this ZIP over your project (Replace when asked):
- Assets/Resources/Models/AstronautEVA.glb, CrewCasual.glb  (new files)
- Assets/Scripts/World/Astronaut.cs, HabitatInterior.cs      (replace)
- Assets/Scripts/Models/CrewRig.cs                           (new)
- Assets/Scripts/Mission1.cs                                 (replace)
- MISSION_MOHAKASH_HANDOFF.md                                (replace)

Play: outside you are the EVA astronaut. Enter the habitat -> you become the casual-dressed crew member.
At the Bunk station press E: you walk to the bed, lie down and sleep (blanket rises). Press E again or move to get up.

If a character is stuck in its standing pose: select the .glb in Unity, Inspector > Animation Method = Legacy, Apply.
Console error "Unity compile": send me the first red line.
