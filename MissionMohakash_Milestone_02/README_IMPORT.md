# Mission Mohakash - how to open and play (Milestone 02)

1. Open **Unity Hub** > open the `MissionMohakash` project (Unity 6000.6.5f1). Wait for the import to finish.
2. If you see pink materials or missing scenes: menu **Mission Mohakash > Rebuild Project Setup** (takes ~10 s).
3. Open `Assets/Scenes/Intro.unity` (Project window > Scenes > double-click Intro) and press **Play**.
   - The intro video plays first (Skip appears after 2 s), then the main menu.
4. Click **START MISSION 1: FIRST LIGHT** > read the briefing > **Plan the loadout** > **LAUNCH**.
5. Click inside the Game view once so the mouse controls the camera. **Esc** opens the pause menu and frees the mouse.

Controls: WASD move - mouse look - Shift sprint - Space jump - E interact/deploy - R rover - Tab systems -
1/2/3 = 1x/2x/4x time - P pause time - Esc menu.

Standalone app: menu **Mission Mohakash > Build macOS App** creates `Builds/Mac/MissionMohakash.app` (double-click to play).
