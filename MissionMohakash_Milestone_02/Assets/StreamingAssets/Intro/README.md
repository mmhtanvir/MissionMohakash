# Intro video

Put the team's intro video in THIS folder:

    Assets/StreamingAssets/Intro/VIDEO-2026-10-08-16-07-16.mp4

(any .mp4 here works; for a future WebGL build name it `intro.mp4`).

The Intro scene plays it full-screen with the aspect ratio preserved (black bars), shows **Skip** after 2 seconds,
then opens the main menu. It plays once per launch. If no video is here, the game goes straight to the menu.
The team video `VIDEO-2026-10-08-16-07-16.mp4` (1280x720 H.264, 10 s) is included here.
