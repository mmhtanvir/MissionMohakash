# Decision log

| # | Decision | Reason |
|---|----------|--------|
| D1 | **Full 3D third-person** presentation. The GDD (§31-32, §45.5) recommends top-down 2D in a web stack and defers 3D. We keep every GDD *system and learning goal* (loadout, power chain, life support, EVA, hazards, report) but present them in 3D. | Owner's explicit request; recorded as a GDD conflict per §45.5 |
| D2 | **Unity 6.6 + URP** instead of the GDD's TypeScript recommendation. | Owner's engine choice |
| D3 | **1 GDD map cell = 10 m in 3D** (GDD uses 100 m cells). Seismometer rule "≥ 8 cells" becomes ≥ 80 m. Rover cost 0.12 PWh per cell becomes 0.012 PWh/m. | A 3 km walk is not playable on foot in 3D |
| D4 | **1x = 30 real seconds per mission hour** (GDD §8 says 10 s). 72 h = 36 min at 1x, 9 min at 4x. EVA is capped at 1x (GDD: "1x for EVA"). | Walking in 3D needs more real time per game hour or a 4 h suit is gone in 40 s |
| D5 | **No construction grid.** Modules chosen in the loadout are placed automatically around the habitat. The "Build" step is represented by the loadout, power switching and seismometer placement. | Scope: the vertical slice favours the full Mission 1 loop (§35 cut line) |
| D6 | **Terrain is procedural, "inspired by" Connecting Ridge.** Not real LOLA data yet. Labelled in the briefing, credits and report. | §38 backup plan; real LOLA processing is the next data milestone |
| D7 | **Power shedding is strict by priority level** (once a level is short, all lower levels are shed). OGS in AUTO is deferrable: it only uses spare power. Battery lockout below 1% until 5% (no flicker). | GDD §14 "lowest priority drops first"; found by tests |
| D8 | Simplifications (labelled in-game): seismometer is powered over the "local network" from the base bus; crew water use is the same inside/outside; suit refill costs 0.06 kg cabin O2 per suit-hour; dose rates are game-mSv. | Readability (GDD §3.1 Accessibility > Fun > Education > Realism) |
| D9 | Polar sun is raised to 13° and ambient "earthshine" fill added. | Real polar sun is lower, but the scene was unreadably dark |
| D10 | Items NOT offered in the M1 loadout although the GDD lists them: NAV, CAM (no gameplay effect implemented yet). Rather than sell items that do nothing, they are omitted. | No fake features |
| D11 | Models: Quaternius Ultimate Space Kit + Quaternius space-suit character, both **CC0**. The kit's own "Astronaut" is a cartoon flamingo/frog/bee, so the human space-suit character is used instead. | Licensing + tone |
| D12 | Scenes contain only a bootstrap object; the world and UI are built at runtime from `Resources`. Scenes/material/UI assets are generated by `Mission Mohakash > Rebuild Project Setup` (real Unity-serialised files, not hand-written YAML). | Robust, diff-friendly, regenerable |
| D13 | UI Toolkit built in C# with one USS file. | Real UI with an EventSystem + Input System module; replaces IMGUI |
| D14 | The intro video is read from `StreamingAssets/Intro` by URL (not a VideoClip import). | Same path works for Mac and a future WebGL build |
