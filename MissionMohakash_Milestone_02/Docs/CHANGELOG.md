# Changelog

## Milestone 02b - simpler menus (2026-10-09)
- Controls list: main menu > Controls, pause menu > Controls, and in-game H / F1 (`UI/ControlsUi.cs`).
- Main menu reduced to PLAY / How to play / Settings / Credits / Quit.
- New Mission Select overlay: 4 cards (Moon blue, Mars orange) with difficulty, duration, objective, focus, status, best score; M1 Launch, M2-4 "Coming in next build". GDD mission names kept.
- Mission Briefing rewritten: story, numbered Mission Plan, Key Ideas.
- Simple Loadout: standard gear always packed + tickable extras until the rocket (540 kg / 125 Cr) is full; full GDD cargo table kept behind "Advanced".
- Editor: Play always starts from the Intro scene (`Editor/PlayFromIntro.cs`).
- Tests 12/12; scripted playthrough with default simple loadout: score 98, 3/3 primary.

## Milestone 02 - rebuild against the GDD (2026-10-09)
- Added the team intro video to StreamingAssets/Intro; verified playback + Skip in the macOS build.
Milestone 01 was a primitive sandbox with invented numbers (the GDD was not available to it). It was replaced.
The original Milestone 01 files are still in `MissionMohakash_Milestone_01/`.

- **GDD read in full** (`Junior_Astronaut_Mission_Trainer_GDD.pdf`, 56 pages). Mission 1 now uses GDD values: 125 Cr / 540 kg loadout,
  equipment table §40, power §14, life support §15, suit §18, hazards §23, scoring §26, report §25.1.
- **Real 3D assets**: CC0 Quaternius models (human space-suit astronaut with Idle/Walk/Run/Wave/Interact/Death animations, rover,
  geodesic habitat, modules, solar arrays, antenna, radar, lander, rocks) imported as GLB via glTFast 6.20.0.
- **Animator setup**: `Resources/Animation/Astronaut.controller` + looping-corrected clips, generated by the setup script.
- **Scenes**: Intro (VideoPlayer, Skip after 2 s, once per launch, falls back to menu) -> MainMenu (3D backdrop, Missions with
  lock state, Settings, Credits & data) -> Mission1.
- **Mission 1 "First Light"**: briefing -> loadout -> landing -> surface ops -> report. Systems: one-minute tick clock with
  pause/1x/2x/4x and auto-slow, power bus with strict priority shedding and battery lockout, OGS OFF/AUTO/ON, CO2 scrubber + cartridges,
  water/food, suit A timers + integrity, walk-back circle, scripted shadow window (h40-46), solar particle event (h22-25) with
  RAD early warning, moonquake window (h52), drivable Scout Rover with battery per metre and 20° slope limit, seismometer
  carry/deploy/reposition with 80 m noise ring, radiation reading, 3 regolith sample sites, solar-array dust cleaning, suit repair with spares.
- **Report**: GDD §26 score + stars, objectives, cause chain, "what would work next time", timeline, science data log with provenance,
  Real-world-vs-game cards.
- **UI**: UI Toolkit (replaces IMGUI). Dark navy / white / orange; status shown by shape + colour.
- **Terrain**: procedural ridge + craters, flattened outpost pad. Labelled "inspired by LOLA", NOT real data.
- **Tests**: 10 EditMode tests (all pass). Automated player playthrough (`-autotest`) with screenshots: success run score 87 (3/3 primary,
  quake recorded); deliberate failure run (no scrubber/battery) fails at h39.4 with cause chain "CO2 -> health 0".
- Fixed during testing: greedy power allocation let low-priority loads run while higher ones were shed (now strict per GDD §14);
  OGS in AUTO could starve other loads at dusk (now uses spare power only); first astronaut model was a cartoon flamingo with a pistol
  (replaced with the human space-suit character).
